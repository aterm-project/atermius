01 — 主机

整个机群，随手可达

紧凑的主机列表、分组和可复用命令。在搜索框里输入一条 ssh 命令就能直接连接。

  • 分组和排序在各端保持一致
  • 搜索框快速连接
  • 跳板主机可保存，也可只给当前标签临时使用

02 — 终端

帮你一起看日志的终端

错误、警告、成功、IP 地址和链接会在普通输出里自动着色，即使远端程序完全不输出颜色。

  • 关键词分组、颜色和词表都可以编辑
  • 回滚缓冲区最多 5,000,000 行
  • SSH 和 Telnet；桌面端还有本机 Shell 和串口

03 — 文件

不离开会话就能管文件

SFTP 和 SCP 文件工作区与终端并排。两台主机之间可以通过 SSH 直传，也可以经本机中转。

  • 跨主机复制和移动
  • Windows 和 macOS 可用系统应用打开远程文件
  • 本地保存后提示上传

04 — 布局

按自己的思路分屏

把终端和文件视图放进并排的面板，再把这套布局存成窗口组合，下次直接恢复。

  • 各端都支持分屏
  • 可保存的窗口组合
  • 桌面端支持独立系统窗口

安全模型

服务端同步的是密文

主机、密钥和密码在设备上加密之后才会同步。同步服务端保存密文记录，并校验带签名的设备身份。

01

本地资料

原生客户端可以只在设备上保存加密资料，完全不连接任何服务端。

02

默认私密

每个账户要么是私密模式（零知识），要么明确设为管理员可见，用户会收到提示，查看行为会被记录。

03

静态加密

服务端数据库使用 SQLCipher 加密，快照也一样，密钥保存在数据卷之外。

04

回滚内容只属于你

写入磁盘的回滚内容用 XChaCha20-Poly1305 加密，密钥只存在于内存中。

远程桌面

平台有原生引擎时直接使用 RDP 和 VNC，否则走服务端网关。还可以经 SSH 跳板主机连接。

◈

面向 AI 工具的 MCP

桌面、Android 和 iOS 可以主动开启 MCP 监听，让外部 AI 工具读取和操作你允许的会话。

⇄

团队与 Vault

组织、角色和团队 Vault。主机可以复制或移动到任何有写权限的 Vault。

◷

临时链接

把某台主机的浏览器访问权限临时交给别人，可设置开始时间、过期时间、次数限制，并可随时撤销。

⌁

关键词高亮

只影响显示：复制的文本、搜索、日志和 MCP 输出都与远端写出的内容完全一致。

◐

主题

应用强调色和终端配色分开设置，终端可以是你想要的样子。

自托管

同步服务端，跑在你自己的机器上

服务端是一个 Rust 服务，附带 Docker Compose 文件，提供加密同步 API、组织管理和临时访问网关。

需要 Docker 和 Compose 2.24 或更高版本。

服务端指南↗
bash
$ git clone https://github.com/aterm-project/atermius.git && cd atermius$ cp deploy/.env.example deploy/.env$ docker compose --env-file deploy/.env -f deploy/compose.yaml \ run --build --rm --no-deps server \ database-key-generate --out /keys/database.key$ docker compose --env-file deploy/.env -f deploy/compose.yaml \ -f deploy/compose.web.yaml up -d --build

打开终端，在任何地方。

构建发布在 GitHub Releases 页面，附带校验和与构建凭证。
