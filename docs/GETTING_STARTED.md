# 首次使用与连接主机

[English](GETTING_STARTED.en.md) · [安装](INSTALLATION.md) · [功能矩阵](FEATURES.md)

## 1. 选择资料保存位置

**本地资料**留在当前设备；**服务端账户**使用自托管实例和同步 Vault。应用会记住选择，可在设置中更改。新浏览器有独立存储，可能需要首次设置；手动锁定及系统安全存储是否可用会影响自动恢复。

账户模式填写实例的完整 HTTPS 来源地址。HTTP 仅用于回环地址开发。第一个账户需要运维人员提供的一次性 bootstrap 令牌，后续账户遵循实例的注册与账户邀请策略；组织加入链接不能绕过账户注册。请独立保管账户流程生成的恢复材料。

### 开发服务器：「允许不安全连接」

登录页的服务器地址下方有 **允许不安全连接（不安全，仅限开发使用）** 开关，仅用于开发。默认关闭，开启时需要确认。对某个服务器开启后，本设备可以连接这个确切地址（协议、主机和端口），即使其证书无法验证（例如自签名或内部 CA 证书），或通过明文 `http://` 连接非回环地址。切勿用于真实数据：网络路径上的任何人都可以读取或篡改传输的全部内容，包括账户密码证明和同步数据。

- 只对这一台服务器生效。其他服务器、SSH 主机密钥校验、RDP 证书确认以及 Vault 数据的端到端加密都不受影响。
- 该选择只随已保存的服务器存放在本设备上，不会同步，也不属于任何 Vault。更换服务器地址不会沿用。如需关闭：退出登录，选择 **更换服务器**，在关闭开关的情况下重新连接。
- 使用期间，登录页、锁定页、工作区和账户设置中会一直显示「不安全连接 — 仅限开发使用」警告，可查看其对应的服务器，且无法关闭。
- 浏览器无法跳过证书检查，并会阻止混合内容，因此 Web 客户端中该开关只能在浏览器本身允许时放行明文 `http://` 服务器。对自签名 HTTPS 开发服务器，请在浏览器或操作系统中信任该证书，或使用原生客户端。

除开发以外的任何用途，都应为服务器配置设备信任的证书，见[服务端指南](install/server.md)。

## 2. 保存主机

在 Home 添加主机，填写名称、协议、地址、端口和登录信息。密码可直接在主机编辑器设置，也可从 Keychain 选择可复用私钥。主机保留自己的认证关联，Keychain 集中管理登录密钥；使用分组继承或跳板时请核对依赖。

通过主机卡片的连接操作打开会话；菜单提供编辑、分享和文件入口。Home 搜索会实时筛选，也支持[快捷连接表达式](QUICK-CONNECT.md)。临时连接不等于保存主机，需要反复使用时请保存。

## 3. 确认目标后开始操作

SSH 公钥指纹应与可信渠道核对；RDP 提示证书时核对目标并确认保存，指纹变化需要重新决定。通用 TLS 错误不一定是证书未信任。

标签和分屏各自持有会话。通过面板把手/菜单分屏、克隆、分离或关闭，具体能力由平台决定；SSH、Telnet 和控制台面板的会话菜单（端口转发、命令历史、搜索、共享、文件、属性、断开）也在把手操作里的 ⋮ 按钮中。网页版有新版本时只在主页标签提示。保存的窗口组合可从 Home 打开。SSH 右侧工具栏提供输出搜索、快捷指令与输入历史。快捷指令先填入输入区，由用户确认执行，详见[终端工具栏](TERMINAL-SIDEBAR.md)。

主机或会话菜单中的 **SFTP / SCP** 打开文件工作区。传输、替换前确认远端目录和本地目标。平台限制见[功能矩阵](FEATURES.md)。本机 Shell 属于桌面能力。串口 Console 支持 Windows 的 COM 端口、macOS 的 /dev/cu.* 设备，以及 Android 上经 USB OTG 连接的 USB 转串口适配器。

## 4. 可选的同步与分享

本地资料不会自动上传到服务端，迁移时使用显式迁移/导入流程。更换设备、删除账户或替换资料前保留备份。

账户模式在账户设置中管理组织，通过主机 **分享…** 入口分享给成员/团队或生成临时链接；相应功能要求服务端公布能力，见[分享指南](SHARING.md)。浏览器常规 SSH 需要配置 Relay，临时访客访问则要求独立的受信网关。

## 5. 整理工作区

用分组整理主机、编辑快捷指令、调整终端配色与按键、保存窗口布局。终端会为普通输出中的 `error`、`warning`、`ok` 等词语以及 IP 地址和链接着色；可在 设置 → 主题 → 关键词高亮 中调整或关闭（[说明](FEATURES.md#terminal-keyword-highlighting--终端关键词高亮)）。SSH 转发入口管理转发规则；保存规则后仍需显式启动。浏览器不能创建系统 TCP 监听器，移动端前后台策略可能中断活动隧道和会话。

连接失败时结合会话/日志信息查看[常见问题](TROUBLESHOOTING.md)。提交问题时不应附密码、私钥或完整访问链接。
